DEPLOY ON VERCEL:
1. Upload index.html and the assets folder to the ROOT of a new GitHub repository.
2. In Vercel choose Add New > Project > Import Git Repository.
3. Framework Preset: Other; Root Directory: ./; Build Command: leave blank; Output Directory: leave blank.
4. Deploy, then add your existing domain in Project Settings > Domains.
5. Follow the DNS records shown by Vercel at your registrar.

IMPORTANT:
This is a responsive, functional visual prototype, NOT a payment-enabled donation service.
Donation amount selector works but no funds can be transferred.
No donation totals, partners, token contract, or environmental results are claimed.
